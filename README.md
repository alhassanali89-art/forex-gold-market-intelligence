# Forex & Gold Market Intelligence

This is a static, browser-based prototype. Open `index.html` to use it.

## Included
- Mobile-friendly dashboard
- Illustrative sample watchlist (not live prices)
- CSV OHLC upload and simple rule-based technical analysis
- Manual WhatsApp `.txt` export/paste keyword review

## Important limitations
This package does NOT connect to live market data, a news provider, an AI model, Supabase, WhatsApp, push notifications, or a broker. Signals are educational examples, not validated recommendations. The sample candles are synthetic.

## GitHub Pages
1. Upload `index.html` and `README.md` to the root of your GitHub repository.
2. In GitHub, open Settings → Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Wait for the published site URL to appear in the Pages section.

Do not put database passwords, Supabase secret/service-role keys, or private chat exports in this public repository.
